# Práctica 1 — Portafolio Vanilla

Portafolio personal construido con **HTML5 + CSS3 + JavaScript ES6+ vanilla**.

## Tecnologías
- HTML5 semántico
- CSS3 (variables, Flexbox, Grid, media queries)
- JavaScript ES6+ (DOM, eventos, validación)

## Secciones
Navbar sticky, Hero, Sobre mí, Proyectos (render dinámico), Habilidades, Contacto (form validado), Footer.

## Ejecutar localmente
Abre `index.html` en el navegador o usa Live Server en VS Code.
